# Modernization Skill

Use this skill when developing reconstruction specifications, migration blueprints, or technology modernizations.

## Principles

1. **Target-Neutrality:**
   - Clearly document *what* the system does and *why*, avoiding legacy framework-specific assumptions.
   - Describe schemas, validation constraints, and workflows in standard declarative formats.

2. **Migration Phasing:**
   - Break large migrations into safe, testable phases.
   - Prioritize backward compatibility and parallel run validation where appropriate.
