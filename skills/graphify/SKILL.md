# Graphify Skill

Use this skill when analyzing codebase dependencies, module coupling, or tracing execution flows.

## Core Operations

1. **Import Graph Traversal:**
   - Trace all internal and external imports across the project.
   - Flag circular dependencies or excessive coupling between components.

2. **Call Hierarchy & Route Tracing:**
   - Map entry points (HTTP handlers, CLI commands, queue consumers) down through service layers to persistence.

3. **Cluster Analysis:**
   - Group files by cohesion to determine high-level logical domains and boundaries.
